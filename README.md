# Trilha Java ao Microsserviço

Repositório dedicado à minha evolução no desenvolvimento backend utilizando Java.

Este projeto acompanha uma trilha prática de aprendizado, começando pelos fundamentos da linguagem Java e evoluindo gradualmente para conceitos utilizados no desenvolvimento de aplicações backend modernas, incluindo Spring Boot, APIs REST e arquitetura de microsserviços.

---

# 🎯 Objetivo

Consolidar conhecimentos em Java através da prática, desenvolvendo exercícios e pequenos projetos que ajudam na construção de uma base sólida para desenvolvimento backend.

A trilha segue uma evolução progressiva:

```
Fundamentos Java
        ↓
Orientação a Objetos
        ↓
Collections e Streams
        ↓
Boas práticas de código
        ↓
Spring Boot
        ↓
APIs REST
        ↓
Arquitetura de Microsserviços
```
